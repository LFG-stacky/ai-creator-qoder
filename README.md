# AI CREATOR — 2026 Qoder 高校创造力大赛参赛项目 (v3.0)

> 让每一个 AI 创意，成为价值。

## 项目简介
**AI CREATOR** 是一款采用 Apple 极简设计语言的电脑宽屏优先 AI 创作者社区与数字/硬件作品交易平台。平台聚焦「发现 → 比选 → 透明分账交易 → 经营分析 → 社区私信协作」全链路闭环，坚持 **80% 创作者高收益分成**，覆盖 AI 游戏、AI 影视、AI App、AI 网页、3D 模型、数字艺术与智能硬件等 12 大领域。

## 核心亮点
- **Apple 级极简视觉与 1.8px 统一矢量图标系统**：支持一键切换浅色 / 深色外观（快捷键 `D`），宽屏 `1360px` 布局与顶部滚动阅读进度条。
- **双栏市场工作台 + 作品横向对比台**：左侧 `270px` 常驻多维筛选（分类 / 数字与实物形态 / 免费与付费 / 仅看开源），支持网格与列表视图切换，并可勾选最多 3 件作品进行参数并排对比。
- **购物袋透明分账结算 + 经营大屏实时联动**：按 `B` 打开购物袋抽屉，实时预览 `80% 创作者实得 / 20% 平台服务费`；模拟结算后自动生成电子授权订单，并即时驱动「经营中心」11 月营收柱状图与订单统计增长。
- **短视频剧场 + 社区 8/4 双栏 + 创作者私信抽屉**：支持剧场预览直达关联作品、话题筛选、星级评价提交以及与任意创作者的一键私信互动。
- **30 秒评委导览与全键盘快捷键**：首屏内置「30 秒亮点导览」，支持 `⌘K`/`/` 全站搜索、`1–6` 快速切页、`N` 发布作品、`?` 查看快捷键指南。
